# 公交换乘优惠 · 单期月结清分台

两家公交公司交换刷卡流水以确认换乘优惠。本应用是一个**单期月结网页**：
接收双方分批上传的 CSV 原档（SQLite 持久化），按引用规则求出包批号对，
一键生成含原始 CSV 与批号清单的 ZIP 清分包。

## 业务规则

### 收件

- 上传时填写：公司（A 甲公司 / B 乙公司）、批号（**从 1 起编**）、
  本批用到的对方最高批号（没引用填 **0**）、CSV 原档。
- **允许乱序到件**：先到第 3 批、后到第 1/2 批都正常登记，页面列出乱序待补批次。
- **原样重传只收一次**：同公司同批号，且引用号、文件 SHA-256 都相同 → 幂等忽略。
- **同号改原档或改引用一律退回**：已收批号不可覆盖，提示改用新批号。
- CSV 原档字节与元数据一并入库，不可变。

### 出包批号对（能同时成立的最靠后一对）

1. 两边都必须**从第 1 批连续纳入**，中间缺批则到此为止；
2. 包内任一批引用的对方批次（`max_other_ref` 及以内）**也必须纳入且原档已收**；
3. **互引且原档齐备的批次可以一起入包**（如 A2 引 B2、B2 引 A2，同时成立）；
4. 在所有可行对中取**分量最大**的一对（最靠后）。实现上从双方连续前缀出发做
   不动点收缩（`app/logic.py::feasible_pair`），并由 200 组随机穷举测试对照验证。

### 打包与下载

- 点击「开始打包」时对**当时已收原档做整份快照**（含 CSV 字节）；
  **打包期间照常收件**，新到件不影响本次结果，下次出包才纳入。
- ZIP 内为双方原始 CSV（按 `company_X/batch_YYYY_原文件名` 存放）、
  批号清单 `manifest.csv`（UTF-8 BOM，含引用号、原始文件名、大小、SHA-256、收件时间）
  和 `package_info.json`（批号对、纳入范围、快照时缺口）。
- **完整生成后才出现下载链接**；任务状态 `running / ready / failed`。
- 失败（如双方第 1 批未齐、写入故障）落库为 `failed`，**可用已收原档重试**，
  重试重新取快照，失败期间到的新件会纳入。

### 网页展示

- 双方各自：已收件数、从 1 连续到第几批、本次可纳入到第几批、
  还缺哪些原档（断点批号）、已到但乱序的批号；
- 全部已收原档明细表；最近 10 次打包任务及下载/重试入口。

## 目录结构

```
app/            Flask 应用（db 持久层 / logic 批号对算法 / packaging 出包 / routes 路由 / templates）
tests/          pytest 自测（19 个用例，含 200 组穷举对照、故障注入、端到端）
demo/run_demo.py  网页试跑样例（纯标准库，生成样例 CSV 并走完整业务流）
Dockerfile / docker-compose.yml
wsgi.py         gunicorn 入口
```

## 用 Docker Compose 启动

```bash
docker compose up --build -d
# 打开 http://localhost:8000
docker compose logs -f
```

SQLite 库与生成的 ZIP 持久化在命名卷 `settle-data`（容器内 `/data`）。
停止：`docker compose down`（加 `-v` 同时清除数据卷）。

## 网页试跑样例

服务启动后，在宿主机运行（仅用 Python 标准库，无需装依赖）：

```bash
python demo/run_demo.py
# 自定义地址/输出目录：
SETTLE_BASE_URL=http://127.0.0.1:8000 SETTLE_DEMO_DIR=./out python demo/run_demo.py
```

脚本会：

1. 乱序上传 A3→A2→B1→A1→B2（含互引 A2↔B2、A3 引 B2）；
2. 演示原样重传幂等忽略、改原档退回、改引用退回；
3. 开始打包并在期间继续上传 A4，验证快照隔离（首包为 A=3/B=2，不含 A4）；
4. 下载 ZIP 并打印清单；再次出包则纳入 A4（A=4/B=2）；
5. 验证只有 failed 任务可重试。

## 本地开发（不用 Docker）

```bash
pip install -r requirements.txt -r requirements-dev.txt
export SETTLE_DB=./data/settle.db SETTLE_PACKAGES=./data/packages
python wsgi.py            # 开发服务器，:8000
pytest -q                 # 自测
```

## 自测覆盖（实测 19/19 通过）

- 表单校验、连续前缀与乱序缺口；
- 引用把批号对压回、互引闭环一起入包；
- 不动点算法与穷举最大可行对的 200 组随机对照；
- ZIP 内容/清单、双方第 1 批不齐拒绝出包、故障注入无半成品、快照隔离；
- HTTP 端到端：幂等/退回、并发打包拦截、ready 后才能下载（否则 409）、失败重试成功。

## 已知边界 / 未做项

- 定位为**单期月结**：没有期间（账期）概念，所有收件共享一个库、一份连续批号序列；
  多期需要先清空/归档数据卷。
- CSV 只做扩展名为 `.csv`、非空、20MB 上限的基本校验，不解析业务字段
  （题目未给出字段规范，原档要求原样保存）。
- 单 gunicorn worker + 线程模型，配合进程内写锁；多实例水平扩展需要改用外部任务队列。
- 没有账号/权限体系，默认假设运行在内网清分终端。
